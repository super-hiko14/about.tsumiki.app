# ブログの書き方

記事は `posts.json` の `"posts"` の中に足していきます。
並び順は**日付で自動**(新しい順)なので、どこに足しても大丈夫です。

## ひな形(これをコピーして使う)

```json
{
  "id": "003",
  "date": "2026.12.01",
  "tag": "update",
  "title": "タイトル",
  "body": "1つめの段落です。\n\n2つめの段落です。改行だけなら\nこのように書きます。"
}
```

前の記事の `}` のうしろに `,` を付けてから貼ってください。

## 項目

| 項目 | 必要? | 中身 |
|---|---|---|
| `id` | 必要 | 記事のURLになる番号(`?post=003`)。ほかの記事と重ならないように |
| `date` | 必要 | `2026.12.01` の形 |
| `tag` | 必要 | `update`(アップデート)/ `tips`(使い方)/ `dev`(開発日誌) |
| `title` | 必要 | タイトル |
| `body` | 必要 | 本文(書き方は下) |
| `excerpt` | なくてOK | 一覧に出る短い説明。書かなければ本文の最初から自動で作る |
| `tagLabel` | なくてOK | タグの表示名。書かなければ `tag` から自動 |
| `draft` | なくてOK | `true` にすると公開しない(下書き) |

前の書き方(`"content": ["1行目", "2行目"]`)もそのまま使えます。

## 本文(`body`)の書き方

JSON の中なので、改行は `\n`、空行は `\n\n` と書きます。

| 書き方 | 見え方 |
|---|---|
| 空行(`\n\n`) | 段落を分ける |
| 改行(`\n`) | 段落の中で改行 |
| `## 見出し` | 見出し |
| `### 小見出し` | 小さい見出し |
| `- 項目` を並べる | 箇条書き |
| `1. 項目` を並べる | 番号つきの箇条書き |
| `> 文` | 引用(まわりを囲む) |
| `**太字**` | 太字 |
| `[文字](https://...)` | リンク(ほかのサイトは新しいタブで開く) |
| `![説明](../sozai/images/xxx.webp)` | 画像(1行にそれだけ書く) |
| `` `コード` `` | コード |
| `¹ ` や `* ` で始まる段落 | 注釈(小さく、線の下に) |

HTML(`<a>` や `<br>` など)もそのまま書けます。

## 例

```json
"body": "今回のアップデートで、タイマー画面がすっきりしました。\n\n## 変わったところ\n\n- 自動停止とグループを1行に\n- 止まっているときの案内文を表示しないように\n\n前の表示に戻したいときは、設定の「タイマー画面を前の表示にする」をONにしてください。\n\n[更新履歴はこちら](https://about.tsumiki.app/changelog/)"
```

## 公開されると

- ブログの一覧に、14日間「NEW」が付きます。
- トップページの「お知らせ」に、いちばん新しい記事が自動で出ます(トップを直す必要はありません)。
- 記事のないタグのボタンは、自動で隠れます。
