語りきれない便利機能

細かいけど地味に嬉しい。
そういうのが盛りだくさん。

途中で再読み込みしてもほぼ無傷

  • 音楽も一回画面を押すだけでまた再開する
  • タイマーは変わらず動き続ける — なんかした?ってぐらい

フォーカスモード(ポモドーロ)

  • 25分集中 / 5分休憩を自動で切り替え
  • オフにすれば普通のタイマーとしても使える

英語完全対応

  • UIを丸ごと英語に切り替え可能
  • 日本語 / 英語をワンクリックで

フォント17種類以上

  • 日本語用 / 英数字用を個別に設定
  • Zen Kaku Gothic Antique, Klee One, Hina Mincho, JetBrains Mono...
