# ツミキappの魅力

## ツミキappとは?
- タイマーで記録
- グラフで可視化
- 音楽で集中
- ToDoで管理  

これらが1ページにすべて備わっている自分好みにカスタマイズできる勉強時間管理ツール。  
**モットー**  
勉強にたくさん集中できるために余計なものは省き、    
カスタマイズで自分好みだらけの設定にして自分だけの勉強時間管理ツールにできる

## カスタマイズ?
- テーマカラーが7色ある。  
  ダークモードもあるぞ。  
  →**これで17色だ。**

- フォント  
  全部で17種類だ。

- 自分だけのものにするためにこれを非表示、これはこうするなどが設定で結構カスタマイズできる。  
  すごい!!

## 機能はどうなんだい
ふふふ。
盛りだくさんだよ。

**音楽機能**  
- ループ、シャッフル、次/前の曲、再生/停止など一般的な機能搭載。
- プレイリストという気分によって曲のリストを丸ごと変えて保存するものも。
  
**ToDo機能**  
- 手軽にタスクを管理できる
- カレンダーがある。
  なお時間指定などはないから手軽なToDo向けだ。  
  この日とこの日+この日からこの日とかもできて結構柔軟性が高い。  
- 優先度、繰り返しなどももちろんある。
  工夫次第ではめっちゃ便利だ。  
  
**フォーカスモード(ポモドーロ･テクニック)**  
- タイマーに搭載されている。
  もちろんフォーカスモードをオフにすれば勉強時間を計るだけも可能だ。  
  
**途中で再読み込みしてもほぼ無傷**  
- 音楽も一回画面を押すだけでまた再開
- タイマーは変わらず動き続ける。  
  なんかした?ってぐらいだ。  
  
**語りきれない細かい地味な便利機能。**  
- タイマー停止時に音楽も停止、英語完全対応、グラフ(種類/表示期間/表示場所もカスタム)、タイムラインバーで一時停止の可視化、タイマーごとのグループ分け、集中しやすい淡い配色のUI、総勉強時間/連続日数等も統計で可視化、チュートリアル搭載、[ヘルプページ](https://about.tsumiki.app/help/)にほぼ載っている、サポート対応(メール: info@tsumiki.app)などなど...。
